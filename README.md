# XPRNT Sticker Imposer

Локальний веб-застосунок для розкладки (імпозиції) прямокутних наліпок на аркуш друку.
Завантажуєш PDF з артворком — застосунок сам рахує, скільки наліпок і як влізе на аркуш,
і генерує готові файли для друку та для плотерного різу.

## Можливості

- Завантаження одного PDF-артворку або кількох одразу (batch-режим).
- Автоматичне визначення розміру наліпки з PDF (TrimBox/MediaBox), з можливістю
  вручну змінити розмір (з опцією зберігати або не зберігати пропорції).
- Вибір аркуша: пресети SRA3 / SRA3+ або довільний розмір.
- Налаштування відступу міток приводки від краю аркуша, поля розмітки, зазору між
  наліпками.
- Автопідбір орієнтації та кількості колонок/рядків для максимального заповнення
  аркуша — або ручне перевизначення сітки й орієнтації.
- Живе SVG-прев'ю розкладки прямо в браузері.
- Генерація архіву (zip), що містить:
  - друк-готовий PDF (артворк, розтиражований по сітці, з мітками приводки);
  - шаблон PDF з мітками (для повторного використання розкладки);
  - файл різу `.plt` (HPGL) для плотера;
  - опційно — векторний PDF контуру різу для сторонніх програм розкрою.
- У batch-режимі однакові за розміром наліпки автоматично діляться одним шаблоном/PLT,
  замість генерації дублікатів.

## Встановлення

Потрібен Python 3.10+.

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python run_server.py
```

або на Windows — подвійний клік по `run.bat`. Сервер підніметься на
`http://127.0.0.1:8000` і сам відкриє цю адресу в браузері за замовчуванням.

## Як користуватись

1. Перетягни PDF-артворк у зону завантаження (або кілька файлів — увімкнеться
   batch-режим).
2. Перевір/скоригуй розмір наліпки, аркуш, відступи, орієнтацію та сітку
   (колонки × рядки) — або залиш авто-підбір.
3. За потреби постав галочку "Векторний PDF контуру різу", якщо він потрібен для
   сторонньої програми розкрою.
4. Заповни номер замовлення, обери матеріал, вкажи кількість наліпок.
5. Натисни "Згенерувати та завантажити" — отримаєш zip із готовими файлами для
   друку та плотера.

## Структура проєкту

```
run_server.py, run.bat   — локальний запуск сервера
server/app.py            — FastAPI-застосунок, підключення роутерів і статики
server/models.py         — моделі запитів/відповідей
server/session_store.py  — тимчасове сховище завантажених файлів
server/core/             — вся розрахункова/генераційна логіка (сітка, PDF, PLT, контур, zip)
server/routes/           — API-ендпоінти
server/utils/            — константи та формування імен файлів
web/                     — фронтенд (HTML/CSS/JS)
```

## Технології

FastAPI, Uvicorn, pypdf, reportlab, PyMuPDF (fitz). Фронтенд — чистий HTML/CSS/JS
без фреймворків.

оновлювати документацію, покроковий git-сетап і підсумок останніх змін) — у файлі

новому комп'ютері, варто відкрити саме цей файл — він містить актуальний стан і
контекст.
